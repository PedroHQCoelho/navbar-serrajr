# Navbar Serra Jr.

Projeto desenvolvido durante um treinamento na **Serra Jr. Engenharia**, empresa júnior da Universidade do Estado do Rio de Janeiro (UERJ), da qual participei durante a graduação.

O exercício teve como foco a construção de uma **barra de navegação (navbar)** para o site da Serra Jr., praticando a estruturação de uma página com HTML e a criação de estilos e comportamento responsivo com CSS.

## Sobre o projeto

A implementação apresenta um cabeçalho com a identidade visual da Serra Jr., incluindo o logotipo e uma navegação com links para diferentes seções do site.

Os itens do menu são:

- Início
- Serra Jr.
- Serviços
- Portfólio
- Blog
- Contatos

Os links utilizam âncoras HTML para apontar para seções identificadas na página. Como este repositório é um exercício focado na navbar, essas seções de destino não fazem parte da implementação apresentada.

## Recursos implementados

- Cabeçalho estruturado com HTML semântico.
- Exibição do logotipo da Serra Jr. com link para a página inicial.
- Menu de navegação com seis itens.
- Efeito visual de hover nos links.
- Menu adaptado para telas menores, com botão de navegação.
- Abertura e fechamento do menu mobile por meio de um checkbox estilizado com CSS.
- Uso do ícone de menu do Font Awesome.

## Tecnologias e recursos

- **HTML5** — estrutura da página e elementos de navegação.
- **CSS3** — layout, tipografia, efeitos visuais e media queries.
- **Font Awesome** — ícone do menu responsivo.
- **Google Fonts** — importação da fonte Lato.
- **Imagens** — logotipo e ícone da Serra Jr.

## Como executar

Não é necessário instalar dependências ou configurar um servidor.

1. Faça o download ou clone este repositório.
2. Abra o arquivo `index.html` em um navegador.
3. Redimensione a janela para visualizar a adaptação do menu em telas menores.
